## Adversarial seams and stop conditions

- Patterns: reject impossible ranges/pools, invalid operations, duplicate default sequences and pagination overflow; stop if public closure requires a new renderer for the three B1 IDs.
- Fractions: reject zero/unsupported denominators, mixed valid/invalid selectors, floating-point equality, improper values outside the approved role, ambiguous equivalents, duplicate/reversed prompts and partition/answer mismatch; stop if the Grade 3 primitives cannot extend without changing their contracts.
- Stories: generate arithmetic before prose; enforce Grade 4 ranges, non-negative subtraction, exact missing-position state, name/object/template repetition caps, referent/pronoun agreement and work-box/key parity; stop on ambiguous multistep language or a required new story renderer.
- Place value: test 1000/9999 boundaries, zero placeholders, mixed aliases, duplicate/out-of-range selections, interval density, endpoints, four-digit number-word length and key parity; stop if number-line labels or words overflow the existing page.
- Algebraic relationships: equation comparison needs exactly one stored equality state; Function Table needs explicit input/output/rule rows and restored key truth; stop if either requires renderer-owned mathematics or a broad new visual system.
- Deferred graphs: symbol/scale caps, ambiguous extrema, label overflow, partial symbols and multiple correct matches remain unresolved. Do not start a Grade 4 graph batch without a separately approved graph role and visual primitive.
