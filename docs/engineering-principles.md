# Yellow Bird Engineering Principles

- One airplane flying.
- Generate once. Transform many times.
- Prefer shared runtime over duplicate logic.
- Routes stay thin.
- Renderers render only.
- Design decisions live in tokens and layout specs.
- New worksheet families and major family redesigns complete the Founder Worksheet Design Preflight before implementation.
- Make the smallest safe change.
- Prefer cleanup over new features.
- Every change should be reversible.
